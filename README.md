# VisuBoard

![VisuBoard Logo](icon.png)

**Unbelievably simple digital signage for Android tablets.** VisuBoard turns
any tablet into a fullscreen, auto-playing showcase for your images and
videos - no cables, no subscriptions, no complicated setup. Import your
media, add your logo, and let it run.

This repository hosts **downloads only** - no source code. Grab the latest
APK from [Releases](../../releases/latest) and sideload it onto your tablet.

## Requirements

- Android 7.0 (Nougat) or newer
- A tablet with a touchscreen

## Installation

1. On the tablet, go to **Settings → Apps → Install unknown apps** and allow
   your browser or file manager to install APKs.
2. Download the `.apk` file from the link above.
3. Open the downloaded file and tap **Install**.

## Features

- Support for images and videos in a single presentation
- Adjustable delay between slides, with videos playing through to the end
  before advancing
- Fit (letterbox) or Fill (crop) display modes
- Customizable logo overlay - size, opacity, edge distance, and position
- Video sound on/off
- Kiosk-ready: runs fullscreen, keeps the screen awake, and auto-starts the
  presentation on launch

## Getting started

1. Launch VisuBoard - it opens straight into the presentation screen.
2. Press and hold anywhere on the screen to open settings.
3. On the **Media** tab, tap **Add from Gallery** or **Add from Files** to
   import images and videos. Files are copied into the app, so the
   presentation keeps working even if the originals are moved or deleted.
4. Reorder media with the arrows on each item, adjust the delay and sound,
   and choose Fit or Fill.
5. On the **Branding** tab, upload a logo (PNG or SVG) and position it on
   your slides.
6. Tap **Start Presentation** to begin.

## FAQ

**Is my media uploaded anywhere?**
No. VisuBoard works entirely offline - imported files are copied into local
app storage on the tablet and never leave the device.

**Will the installed APK trigger a "Play Protect" warning?**
Yes, likely - this is expected for any app installed outside the Play Store.
Tap "Install anyway" if you trust the source (this repository).

**How do I update?**
Download the latest APK from [Releases](../../releases/latest) and install
over the existing app. Your media and settings are preserved.
